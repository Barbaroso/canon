# Security Policy

## Supported Versions

Security updates are provided for the latest commit on the default branch.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately through
GitHub's private vulnerability reporting flow:

https://github.com/Barbaroso/canon/security/advisories/new

Include:

- A clear description of the issue and potential impact
- Steps to reproduce
- Any proof-of-concept details needed to validate the report

Please do not disclose vulnerabilities publicly until we have investigated and
provided a fix or mitigation.

We will acknowledge receipt as quickly as possible and keep you informed through
triage, validation, and remediation.
